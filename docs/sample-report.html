Defects

High A double tap on Place order leaves a blank screen

lib/presentation/home_screen.dart:27 · macOS desktop

Steps

  1. Sign in and add Product 0 to the cart
  2. Tap Checkout
  3. Double tap Place order: pilot tap --text "Place order" --double

Expected

One order is placed and the Home screen shows "Order placed".

Actual

A second later the app shows a blank page. pilot snapshot prints "nothing is on screen".

Evidence

The button waits for placeOrder() and then closes the dialog, and nothing stops a second tap in between, so two routes are closed: the dialog and the Home screen behind it. Saved as pilot/double_order.flow.

High Product 7 cannot be added to the cart

lib/presentation/home_screen.dart:94 · macOS desktop

Steps

  1. Sign in
  2. Scroll to Product 7
  3. Tap its add-to-cart button

Expected

Product 7 is added and the cart summary changes.

Actual

Nothing is added. The app throws IntegerDivisionByZeroException.

Evidence

pilot printed: ! app error: IntegerDivisionByZeroException at lib/presentation/home_screen.dart:94. Every other product can be added.

High Cancel in the sign-out dialog signs the user out

lib/presentation/settings_screen.dart:17 · macOS desktop

Steps

  1. Sign in and open Settings
  2. Tap Sign out
  3. Tap Cancel in the dialog

Expected

The dialog closes and the user stays signed in, on Settings.

Actual

The Sign in screen appears: the user has been signed out.

Evidence

The snapshot after tapping Cancel shows the Sign in screen. Both dialog actions close the dialog with the same answer.

Medium The rating control throws an accessibility assertion

lib/presentation/rating_stars.dart:16 · macOS desktop

Steps

  1. Sign in
  2. Open any product, for example Product 6

Expected

The page opens without errors and a screen reader can raise or lower the rating.

Actual

The app throws: A SemanticsNode with action "increase" needs to be annotated with either both "value" and "increasedValue" or neither.

Evidence

pilot printed that app error as the page opened. The widget tells a screen reader its value and that it can be changed, but not what it would change to.
